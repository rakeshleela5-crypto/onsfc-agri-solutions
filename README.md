## 🏛️ Executive Overview

**ONSFC Agri Solutions Private Limited** is a farmer-first agricultural aggregation, pre-cleaning, pneumatic de-stoning, and dry godown enterprise headquartered at **Gooty (Anantapuramu District, Andhra Pradesh)** along the critical **NH-44 Expressway Corridor**.

### 🌟 Core Mandate & Differentiators
1. **Direct Dryland Farmer Origin**: Aggregating directly from **5,000+ dryland farming families across all 24 revenue villages of Gooty Mandal**, completely eliminating predatory village middlemen and mandi brokers.
2. **1-Acre First-Mile Processing Hub**: Located on NH-44 equipped with multi-stage pneumatic gravity de-stoning tables (guaranteeing **0.00% stones & silica**), optical sortex color grading (99.8% purity), and moisture-controlled dry godowns (<12% moisture).
3. **100% Dry Produce & Commercial Cash Crops ONLY**: **STRICTLY ZERO PERISHABLE VEGETABLES, ZERO FRUITS**. We specialize exclusively in high-value, long shelf-life dry staples and industrial cash crops.
4. **1,040 Audited Commercial Off-Takers**: Serving an audited, twenty-four-tier demand network spanning automotive plants (KIA, Hyundai, TVS), steel townships (JSW Steel Toranagallu), railway pantry guilds (IRCTC, R.K. Associates), Big-4 tech park corporate dining (Sodexo, Compass), hospital dietary chains (Apollo, Manipal, VIMS), universities, and sacred temple Annadhanam trusts (Hampi, Sandur, Tirupati).

## 💻 Tech Stack & Architecture

- **Frontend (`web/`)**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons. Designed with Google Chrome Modern Web Guidance standards.
- **Backend API (`server/`)**: FastAPI, Python 3.12, Uvicorn, Pydantic validation, CORS middleware.
- **Database (`data/`)**: SQLite local engine (`onsfc_database.db`) + Production PostgreSQL / Supabase DDL schema (`onsfc_production_schema.sql`).
- **CRM & Outreach Engine (`scripts/` & `proposals/`)**: Automated proposal generator, Sellbird CRM integration, and outbox campaign staging.

## 🚀 Quickstart Guide

### 1. Run the Web Application
```bash
cd web
npm install
npm run preview -- --port 3000 --host
# Access at http://localhost:3000
```

### 2. Run the REST API Server
```bash
python server/api_server.py
# Access API at http://localhost:8000
# Interactive Swagger Documentation at http://localhost:8000/docs
```
